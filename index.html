What is MakeIt?

MakeIt is a personal desktop application that helps gaming content creators automate their video workflow. It processes gameplay recordings and can automatically share highlight clips to social media platforms.

How It Works

  • Record - Capture gameplay using OBS Studio or PS5 recording
  • Process - MakeIt analyzes the video and identifies highlight moments
  • Convert - Clips are converted to vertical 9:16 format for social media
  • Share - Automatically post to TikTok and Instagram with captions

TikTok Integration

MakeIt uses TikTok's Content Posting API to:

  • Upload vertical video clips directly from the desktop application
  • Add captions with game titles and relevant hashtags
  • Post clips to the user's personal TikTok account

This is a personal automation tool - it only posts to the account of the person running the application. No third-party access or multi-user functionality.

Platform

MakeIt runs as a desktop application on macOS. It is a command-line tool designed for personal use by the content creator.
