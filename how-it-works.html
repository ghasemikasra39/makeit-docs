How MakeIt Works

A complete automated pipeline from gameplay recording to published social media content.

1

🎮 Record Your Gameplay

Capture your gaming sessions using your preferred recording software. MakeIt works with any standard video format.

Supported Sources

  • OBS Studio recordings and replay buffer
  • PlayStation 5 captured clips
  • Xbox Game DVR recordings
  • NVIDIA ShadowPlay captures
  • Any MP4, MOV, MKV, or AVI file
2

🔍 Intelligent Processing

MakeIt analyzes your video files and automatically identifies the most exciting moments. The AI-powered detection looks for action peaks, kill feeds, and highlight-worthy sequences.

What Happens

  • Video analysis using intelligent algorithms
  • Automatic highlight moment identification
  • Clip extraction with configurable duration
  • Audio level normalization
  • Quality optimization for social platforms
3

✂️ Vertical Conversion & Editing

Your horizontal gameplay clips are automatically converted to perfect 9:16 vertical format. Custom overlays, intros, and outros are added to create professional-looking content.

Conversion Features

  • Intelligent 16:9 to 9:16 cropping
  • Center-of-action detection keeps focus on gameplay
  • Animated intro sequences
  • Call-to-action outro cards
  • Text overlays and captions
  • Hardware-accelerated encoding for speed
4

🚀 Automatic Publishing

Finished clips are automatically uploaded to TikTok and Instagram with optimized captions and hashtags. Schedule posts or publish immediately.

Publishing Features

  • Direct posting to TikTok via Content Posting API
  • Instagram Reels posting via Graph API
  • Auto-generated captions with game titles
  • Relevant hashtag suggestions
  • Scheduled posting queue
  • Post history tracking and analytics
Requirements

Technical Requirements

What you need to run MakeIt on your system.

💻 System Requirements

macOS 12.0 or later. Python 3.11+ with ffmpeg installed. Minimum 8GB RAM recommended for video processing.

🔑 API Access

TikTok Developer account with Content Posting API access. Instagram Business or Creator account with Graph API access.

☁️ Cloud Storage

AWS S3 bucket for temporary video hosting during the upload process. Videos are automatically deleted after posting.
