About MakeIt

MakeIt was born from a simple frustration: spending more time editing and uploading gaming clips than actually playing games.

As a gaming content creator, I found myself spending hours every week cutting clips, converting formats, adding overlays, and manually posting to different platforms. The content creation pipeline was tedious and time-consuming.

MakeIt is the solution — an automated pipeline that handles everything from raw gameplay recordings to published social media posts. Record your gameplay, and MakeIt takes care of the rest.

Technology

Built With Modern Tech

MakeIt is built with reliability and performance in mind.

🐍 Python

Core application built with Python for powerful video processing and API integrations.

🎬 FFmpeg

Industry-standard video processing for format conversion, encoding, and overlay composition.

🎵 TikTok API

Official Content Posting API integration for direct video publishing.

📸 Instagram API

Graph API integration for posting Reels content directly to Instagram.

☁️ AWS S3

Temporary cloud storage for video hosting during the platform upload process.

🗄️ SQLite

Local database for tracking post history and managing content queues.

Our Mission

Gaming content creators shouldn't have to choose between playing games and growing their audience. MakeIt's mission is to eliminate the tedious parts of content creation so creators can focus on what they love — playing games and engaging with their community.

Privacy Commitment

MakeIt is designed with privacy as a core principle. Your gameplay recordings, API credentials, and personal data never leave your machine except when explicitly posting to social platforms. There's no tracking, no analytics, and no cloud processing — just a local application that respects your privacy.

Open Development

MakeIt is developed openly. Questions, feedback, and suggestions are always welcome. The goal is to build a tool that genuinely helps gaming content creators streamline their workflow.
