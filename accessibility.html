Accessibility Statement

Our commitment to making content accessible to everyone

Last updated: August 2026

Our Commitment

I am committed to ensuring digital accessibility for people with disabilities. I am continually improving the user experience for everyone, and applying the relevant accessibility standards to ensure I provide equal access to all users.

Accessibility Features

This website incorporates the following accessibility features:

  • Semantic HTML: Proper heading structure and semantic elements for screen reader compatibility
  • Keyboard Navigation: All interactive elements are accessible via keyboard
  • Alt Text: Descriptive alternative text for images
  • Color Contrast: Text and interactive elements meet WCAG color contrast requirements
  • Responsive Design: Content adapts to different screen sizes and zoom levels
  • Focus Indicators: Visible focus states for interactive elements
  • ARIA Labels: Accessible names for buttons and interactive components
  • Skip Links: Navigation shortcuts for screen reader users

Conformance Status

I strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. These guidelines explain how to make web content more accessible for people with disabilities, and user-friendly for everyone.

Third-Party Content

This website embeds content from third-party platforms including:

  • YouTube videos (embedded players)
  • Social media links and widgets

While I strive to ensure all content is accessible, I cannot guarantee the accessibility of third-party content. I encourage users to contact these platforms directly for accessibility-related concerns with their content.

Browser Compatibility

This website is designed to work with modern web browsers including:

  • Google Chrome (latest version)
  • Mozilla Firefox (latest version)
  • Safari (latest version)
  • Microsoft Edge (latest version)

Assistive Technologies

This website is designed to be compatible with the following assistive technologies:

  • Screen readers (NVDA, JAWS, VoiceOver)
  • Screen magnification software
  • Speech recognition software
  • Keyboard-only navigation

Known Limitations

Despite my best efforts, there may be some limitations:

  • Some older video content may not have captions
  • Some decorative images may lack alt text as they are not essential for understanding
  • Third-party embedded content may have accessibility limitations

Continuous Improvement

I am committed to continuously improving the accessibility of this website. I regularly review and update content to ensure it meets current accessibility standards and best practices.
